## Features

Do you play on servers with multiple proxy IPs (e.g., `play.pepeland.net`, `issues.pepeland.net`) and hate losing your Litematica placements when switching between them? **LitematicaSync** is here to fix that!

- **IP Grouping**: Combine multiple server addresses into a single group. Litematica placements will automatically sync and show up across all IPs in that group!

## How to Use

1. Install the mod along with its dependencies.
2. Launch the game and open the **ModMenu**.
3. Find **LitematicaSync** and open its settings.
4. Create a new group (e.g., "Pepeland").
5. Add all the IP addresses used by that server (e.g., `play.pepeland.net`, `issues2.pepeland.net`).
6. Done! Placements made on one IP will now show up on the others.

By default, the mod comes pre-configured with a group for **Pepeland**!

## Dependencies

To use this mod, you need the following installed:

- [Fabric API](https://modrinth.com/mod/fabric-api)
- [Litematica](https://modrinth.com/mod/litematica)
- [MaLiLib](https://modrinth.com/mod/malilib)
- [ModMenu](https://modrinth.com/mod/modmenu) _(Recommended for accessing the config)_

Играете на серверах с несколькими IP-адресами и устали терять свои схемы Litematica при переключении между ними? **LitematicaSync** решит эту проблему!

## Как использовать

1. Установите мод и все его зависимости.
2. Запустите игру и откройте **ModMenu**.
3. Найдите **LitematicaSync** и откройте его настройки.
4. Создайте новую группу (например, "Pepeland").
5. Добавьте все айпи адреса, которые используются на этом сервере (например, `play.pepeland.net`, `issues2.pepeland.net`).
6. Готово! Схемы, размещенные на одном айпи, теперь будут отображаться и на остальных.

По умолчанию мод уже настроен для работы с серверами **Pepeland**!
